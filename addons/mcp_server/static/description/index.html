MCP Server for Odoo

Expose Odoo to Claude and any MCP client — safely.

Turns Odoo into a remote Model Context Protocol (MCP) connector over HTTP with:

  • MCP Streamable HTTP transport (JSON-RPC 2.0) at POST /mcp
  • Built-in OAuth 2.1 Authorization Server (Authorization Code + PKCE, DCR, RFC 8707)
  • Tool/Resource registry that domain add-ons plug into
  • Generic, admin-configurable model access engine (allow-listed CRUD)
  • Two-step propose/confirm safety on every write
  • Full audit trail with pivot/graph analytics and sensitive-action alerts

Every tool executes strictly as the authenticated Odoo user — ACL, record rules and field security always apply.
